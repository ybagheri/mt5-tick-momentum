# اکسپرت Tick Momentum Burst (نسخه فارسی)

**ترکیب «جهش مومنتوم تیک» + «سر‌به‌سر هزینه‌محور» + «تریلینگ‌استاپ پویا»** — یک اکسپرت MQL5
که بررسی می‌کند آیا رفتار جهت‌دار بسیار کوتاه‌مدت در **جریان تیک MT5** می‌تواند یک مزیت
معاملاتی روی نمادهای CFD (مثل US30، US100، US500، XAUUSD، EURUSD و…) داشته باشد یا نه.

> **محدودیت مهم CFD (اول بخوانید).** این اکسپرت فقط *رفتار قیمتی تیکِ ارائه‌شده توسط بروکر*
> را اندازه می‌گیرد. در CFDها جریان سفارش متمرکزی وجود ندارد. تیک UP به معنی
> «خرید نهادی» **نیست** — فقط یعنی کوتِ بروکر بالا رفته است. پروژه بررسی می‌کند که آیا
> این رفتار، *بعد از اسپرد، کمیسیون و اسلیپیج* ارزش پیش‌بینی دارد یا نه.
> پاسخ صادقانه ممکن است **«نه»** باشد.

## وضعیت

پیاده‌سازی تحقیقاتی، نسخه ۱٫۰۰. مقادیر پیش‌فرض **اولیه و بهینه‌نشده‌اند**.
هیچ ادعای سودآوری وجود ندارد. نگاه کنید به `docs/RESEARCH_REPORT.md`.


## معماری

| ماژول | وظیفه |
|---|---|
| `CTickDataCollector` | بافر چرخشی N تیک آخر، طبقه‌بندی UP/DOWN/NEUTRAL با میدپرایس، بازیابی تاریخچه با `CopyTicks` |
| `CMarketMetrics` | نسبت جهت‌دار، جابه‌جایی قیمت (پوینت)، نرخ تیک‌برثانیه روی پنجره |
| `CMomentumDetector` | تشخیص جهش با چند شرط هم‌زمان: نسبت ∧ جابه‌جایی ∧ نرخ تیک ∧ توافق جهت |
| `CSignalEngine` | گیت‌های ورود: جهش + اسپرد + سقف پوزیشن + کول‌داون + قفل ریسک + بازار غیرعادی |
| `CSymbolInfoCache` | مشخصات پویا‌ی نماد (دیجیت، سایز/ارزش تیک، محدوده حجم، استاپ/فریز لول) |
| `CMoneyMath` | تبدیل‌ها: `money = dist/tickSize*tickValue*vol`، رعایت استاپ‌لول، رُند به تیک |
| `CCostCalculator` | هزینه اسپرد، کمیسیون *تخمینی* (قبل/حین معامله) در برابر کمیسیون *واقعی* (هیستوری معاملات)، قیمت واقعی سر‌به‌سر |
| `CPositionSizer` | لات ثابت + حالت اختیاری ریسک‌درصدی (نسخه ۱٫۲۰، پیش‌فرض خاموش) |
| `CTradeExecutor` | سفارش مارکت با `CTrade`، حدضرر/حدسود پولی، اصلاح به قیمت واقعی اجرا، بررسی retcode |
| `CBreakEvenManager` | انتقال حدضرر به نقطه سر‌به‌سر واقعی وقتی هزینه‌ها پوشش داده شد؛ هرگز سر‌به‌سر تقلبی |
| `CTrailingStopManager` | فقط سفت‌کردن حدضرر (خرید فقط بالا / فروش فقط پایین)، رعایت استاپ‌لول، فعال‌سازی بعد از سر‌به‌سر |
| `CRiskManager` | کول‌داون، سقف معامله روزانه، قفل ضرر متوالی، قفل ضرر روزانه، وتوی بازار غیرعادی |
| `CTradeJournal` | ثبت هر معامله (متریک‌های ورود، MFE/MAE، دلیل خروج) + خروجی CSV اختیاری |
| `CStrategyController` | ماشین حالت + ارکستراسیون؛ مدیریت پوزیشن باز **همیشه اول** در هر تیک اجرا می‌شود |

ماشین حالت: `WAITING → SIGNAL → ORDER → OPEN → COST_COVERED → BE → TRAIL → (بسته‌شدن) → COOLDOWN → WAITING`.
امن در برابر ری‌استارت: موقع اجرا به پوزیشن خودش (نماد + مجیک‌نامبر) وصل می‌شود.

## شروع سریع (Strategy Tester)

۱. محتویات `MQL5/` را در پوشه دیتای MT5 کپی و در MetaEditor کامپایل کنید (F7، بدون خطا).
۲. تستر: حالت **Every tick based on real ticks**، مثلاً نماد US30، بازه‌ای با تیک واقعی.
۳. کمیسیون را هم در تنظیمات تستر و هم در ورودی `InpCommissionPerLot` یکسان بگذارید.
۴. روش کامل: `docs/BACKTEST_GUIDE.md`. توضیح تک‌تک ورودی‌ها: `docs/INPUTS_GUIDE.md`.

## مدل کمیسیون (تخمینی در برابر واقعی)

- **تخمینی** (`InpCommissionPerLot`، تک‌طرف برای ۱٫۰ لات؛ پیش‌فرض ×۲ برای رفت‌وبرگشت)
  فقط *قبل و حین* معامله برای محاسبات سر‌به‌سر استفاده می‌شود.
- **واقعی** موقع بسته‌شدن از هیستوری معاملات (`DEAL_COMMISSION`، هر دو لگ) خوانده
  و جداگانه در ژورنال ثبت می‌شود. این دو هرگز با هم قاطی نمی‌شوند.

## ایمنی

بدون مارتینگل / گرید / میانگین‌گیری / ضریب جبرانی. پیش‌فرض حداکثر ۱ پوزیشن.
فیلتر اسپرد، کول‌داون، قفل ضرر روزانه، قفل ضرر متوالی. فقط پوزیشن‌های خودش
(نماد + مجیک‌نامبر) را مدیریت می‌کند. نگاه کنید به `docs/INPUTS_GUIDE.md` و `HANDOFF.md`.
